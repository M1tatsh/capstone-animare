# ANIMARE CAPSTONE PROJECT

## What is Animare?

Welcome to Death Art Studio's capstone project, Animare! Animare is a 2.5D platformer about a shapeshifting Reaper who must climb the Tower of Memories to save the corrupt souls of the afterlife. Use your shapeshifting powers and puzzle solving skills to save the souls!

This is a repository for the game assets, build versions, and various documentation on the project.
